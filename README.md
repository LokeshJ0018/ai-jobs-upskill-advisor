# AI Jobs Impact & Upskill Advisor

A student-focused web application that explores the impact of Artificial Intelligence on careers and recommends skills for future career development.

## Features
- Career selection across five job roles
- Skill-gap checklist and coverage score
- Career-specific AI impact explanations
- Personalized 30-day upskilling roadmap
- Responsive dashboard
- Print or save results as PDF

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Select a career and your existing skills.
4. Click **Analyze my career** to view recommendations.

## Project Limitation
This version uses a rule-based recommendation engine. It does not use a trained AI model or live job-market data. Career impact explanations are educational summaries, not predictions of individual job loss.
